## Brief
Led development of an Azure Marketplace onboarding platform with a Go/gRPC and MongoDB backend plus a Next.js and React frontend.

## Problem
Customers needed a secure, repeatable path from marketplace purchase to a working tenant, followed by immediate visibility into the network data available after setup.

## Approach
I led the architecture and implementation across authentication, tenant provisioning, backend services, frontend onboarding, and the first visibility experience.

## Highlights
- Implemented OAuth2 authentication and per-tenant deployment flows.
- Built Go/gRPC services with MongoDB for provisioning and tenant context.
- Created a Next.js and React product surface for guided onboarding.
- Designed a visibility dashboard capable of analyzing 25,000+ network traffic flows per tenant context.

## Outcome
Delivered a scalable onboarding and visibility platform that helped customers move from activation to useful network insight faster.

## Stack
Next.js, React, Go, gRPC, MongoDB, OAuth2, Azure Marketplace, multi-tenant architecture.
